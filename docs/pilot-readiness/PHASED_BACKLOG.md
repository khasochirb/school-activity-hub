# Pilot-Readiness Phased Backlog

## Planning rules

- This backlog is a recommendation, not authorization to implement or launch.
- **Blocker** items must be complete before real-student onboarding unless the go/no-go authority records an explicit lawful and safeguarding-safe alternative.
- Schema changes are marked as possible, not pre-approved. Every eventual schema change must follow the repository schema-alignment rule and a reviewed migration.
- School/legal approval includes ethics, safeguarding, privacy, or controller approval where relevant.
- Complexity estimates are relative: **small**, **medium**, or **large**.

## Recommended immediate next phase

Proceed to **Phase 2: technical stabilization and security** as a non-production engineering phase. Run Phase 3 governance work in parallel because technical readiness alone cannot authorize a child-facing pilot. Do not onboard real students until Phase 2 blockers, applicable Phase 3 blockers, and the complete go/no-go checklist are approved.
